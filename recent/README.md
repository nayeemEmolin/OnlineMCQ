# Recent Exam Corner

A static, GitHub Pages-ready hub for recent competitive-exam papers and interactive mocks. The CAAB, Bank Senior Officer, and BPSC Assistant Director (Non-Technical) sets are interactive. The BPSC Assistant Director Set 3 was OCR-transcribed into 99 digital MCQs with answer explanations, subject/topic filters, direct exam mode, and one-by-one practice. The source marks question 100 as unclear, so it is excluded rather than guessed.
