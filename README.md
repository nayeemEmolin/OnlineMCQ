# CAAB Senior Officer Preliminary Exam (2024)

এটি একটি সম্পূর্ণ static, single-page exam app। `index.html`-ই একমাত্র প্রয়োজনীয় ফাইল; কোনো server, package install বা external library লাগে না। কোনো scan/image HTML-এ সংযুক্ত নেই।

## লোকালভাবে চালানো

`index.html` ফাইলটি Chrome/Edge-এ খুললেই পরীক্ষা চালু হবে।

## GitHub Pages-এ হোস্ট

1. GitHub-এ একটি নতুন repository তৈরি করুন।
2. এই ফোল্ডারের `index.html` (চাইলে `README.md`-সহ) repository-র root-এ upload/commit করুন।
3. Repository → **Settings → Pages** খুলুন।
4. **Deploy from a branch** নির্বাচন করে `main` branch এবং `/(root)` নির্বাচন করুন; **Save** চাপুন।
5. GitHub যে Pages URL দেখাবে, সেটি খুলে পরীক্ষা দিন। প্রকাশ হতে কিছুক্ষণ লাগতে পারে।

## অন্তর্ভুক্ত সুবিধা

- ৮০টি ডিজিটাল MCQ, বিষয়ভিত্তিক filter ও question navigator
- ৫০ মিনিটের countdown; সময় শেষ হলে auto-submit
- উত্তর পরিবর্তন, unanswered count এবং progress indicator
- submit-এর পর মোট/বিষয়ভিত্তিক স্কোর, সঠিক-ভুল রং এবং প্রতিটি প্রশ্নের ব্যাখ্যা
- বাংলা/ইংরেজি mixed question text এবং responsive mobile layout

## পাঠ ও উত্তর যাচাই সম্পর্কে

প্রশ্নপত্রের ছবির অস্পষ্ট অংশে OCR পাঠ স্বাভাবিকীকরণ করা হয়েছে। কয়েকটি প্রশ্নে অপশন/উত্তরসূচির ত্রুটি পাওয়া গেছে; সেগুলো রিভিউতে ব্যাখ্যা করা হয়েছে এবং নির্ভরযোগ্য উত্তর নির্ধারণ করা না গেলে স্কোর থেকে বাদ। তাই স্কোরের denominator ৮০-এর কম হতে পারে। এটি ব্যক্তিগত অনুশীলনের জন্য; official answer key নয়।
